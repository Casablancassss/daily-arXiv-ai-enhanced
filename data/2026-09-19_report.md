## 📄 论文 1 - 相关性: 35%
**标题:** Can Vision-Language Models Judge Olympic Diving? From Reasoning to Scores in Zero-Shot Action Quality Assessment
**作者:** Henry O. Velesaca, David Freire-Obregon, Luigi Miranda
**arXiv:** https://arxiv.org/abs/2609.19354

**相关性说明:** The paper uses VLMs for action quality assessment in sports videos, which is a different application domain from 3D motion generation. While both involve human motion analysis, the research profile focuses on GENERATING 3D motions from video priors, not evaluating/assessing existing motions. The paper doesn't address bridging 2D video priors to 3D motion space, extracting guidance features for motion synthesis, or ensuring temporal consistency in generation. Only shared element is using VLMs, but for completely different purposes (evaluation vs. generation guidance).

**摘要:** 本文研究了开源视觉语言模型(VLMs)在奥运跳水视频零样本动作质量评估(AQA)中的应用，提出了一种结合TF-IDF降维和集成学习的回归框架，在AQA-7数据集上实现了0.67的Spearman相关系数。

## 📄 论文 3 - 相关性: 30%

**作者:** Guangzhao He, Hadar Averbuch-Elor, Wei-Chiu Ma
**arXiv:** https://arxiv.org/abs/2609.20819

**相关性说明:** This paper focuses on evaluating visual memory capabilities of 4D foundation models (using 360° videos for object permanence evaluation), which is a DIFFERENT application domain from 3D motion generation. **摘要:** PersistBench是一个用于评估4D基础模型视觉记忆能力的数据集和指标套件，通过360°视频作为全知ground truth，从对象永久性、运动连续性和外观保持三个方面评估模型的记忆能力。研究发现当前模型在对象离开视野后记忆显著退化。
