## 📄 论文 1 - 相关性: 45%
**标题:** PAMI: Part Anchored Motion for Text to Human-Object Interaction Generation
**作者:** Chuqiao Li, Xianghui Xie, Yong Cao
**arXiv:** https://arxiv.org/abs/2609.38466

**相关性说明:** The paper is related to Computer Graphics and human motion generation (specifically human-object interaction), which is in the same general application domain. However, there is a significant mismatch: (1) The research profile focuses on using VIDEO priors for 3D motion generation with video generation models and VLM-based quality supervision, while PAMI uses TEXT-to-motion generation with VAE-based methods - completely different input modality and architecture. (2) The pain points in the profile emphasize bridging 2D video features to 3D motion and temporal consistency from video, but PAMI addresses text-based HOI generation with contact geometry issues. (3) The methods listed (Wanxiang, Seedance, VLM, visual feature extraction) are not used in PAMI. While both involve 3D human motion, the approach, input source, and technical focus are substantially different.

**摘要:** PAMI是一种基于部分锚点的人-物交互(HOI)生成框架，通过让身体部位锚点投票来确定物体运动，解决传统方法中物体漂移、接触缺失和穿模问题。


## 📄 论文 2 - 相关性: 35%
**标题:** Unveiling the Value of Motion for Cinematic Camera Trajectories
**作者:** Ziqi Zhou, Yujian Yuan, Laura Sevilla-Lara
**arXiv:** https://arxiv.org/abs/2609.38683

**相关性说明:** This paper is about CAMERA TRAJECTORY generation (for cinematography), not 3D HUMAN MOTION generation from video priors. While both are in Computer Graphics, they represent different application domains: camera path planning vs. character motion generation. The research profile focuses on extracting visual features from video and generating 3D human motions with temporal consistency, whereas this paper deals with text-to-trajectory generation and trajectory-text alignment. The methods (text-to-trajectory with direction/velocity decomposition) and data (CineScript dataset) are unrelated to video-to-motion generation pipelines like Wanxiang or Seedance. This is a case of using similar generative AI methods but in a completely different application domain.

**摘要:** 本文提出将电影摄影机轨迹从传统的每帧姿态表示分解为方向和速度两个分量，这种表示方法在轨迹-文本对齐和文本-轨迹生成任务中都取得了显著优势，并据此提出了CineGEN生成模型和CineScript数据集。


## 📄 论文 3 - 相关性: 35%
**标题:** MegaAvatar: Controllable Talking Avatar Generation
**作者:** Junyao Gao, Sibo Liu, Weidong Zhang
**arXiv:** https://arxiv.org/abs/2609.39273

**相关性说明:** Uses similar methods (video generation model Wan2.2-TI2V-5B, SMPL-X for 3D guidance) but addresses a different application domain. The paper generates 2D talking avatar videos FROM audio/3D guidance, while the research profile focuses on extracting 3D motion FROM video (2D to 3D). This is essentially the reverse direction - the profile needs video-to-motion extraction, not motion-to-video generation. The paper shares the computer graphics domain and uses related technologies but doesn't address the core pain points of bridging 2D video features to 3D motion output.

**摘要:** MegaAvatar是一个基于Wan2.2-TI2V-5B模型的可控 talking avatar 生成框架，通过引入SMPL-X衍生的3D引导实现对身体姿态和头部运动的全局控制。


## 📄 论文 4 - 相关性: 35%
**标题:** GLARE: Generating Listening Heads with Appropriate Reactions
**作者:** Zikai Liao, Yumin Suh, Yi Ouyang
**arXiv:** https://arxiv.org/abs/2609.40317

**相关性说明:** This paper is about generating listening head behaviors (facial/head animations like nodding, smiling) in conversations. While it's in Computer Graphics and deals with human animation, the application domain is fundamentally different from the research profile's focus on 3D human MOTION generation (full-body skeletal motion). GLARE addresses 2D/3D talking head generation from audio, not extracting 2D video priors for 3D motion generation or bridging 2D visual features to 3D motion representation. The pain points and methods (video generation models for motion, VLM for quality supervision, visual feature extraction for downstream motion models) don't align - this paper uses audio-driven generation with flow matching transformers for facial animation, not the video-to-motion pipeline described in the profile.

**摘要:** 本文针对对话中自然倾听行为生成进行研究，提出三方面贡献：1）构建了包含约147小时说话者-倾听者配对视频和64,557个事件级反应标注的数据集；2）提出基于流匹配变换器的音频驱动模型GLARE，采用Qwen2-Audio的韵律条件编码和时序反应损失；3）提出反应导向的评估协议（R-F1、R-tIoU、R-ATD、R-FID）。实验表明该方法在视觉保真度和反应级指标上均优于先前方法。


## 📄 论文 5 - 相关性: 30%
**标题:** Learning Semantic Inpainting for Animatable Gaussian Head Avatars
**作者:** Pilseo Park, Fizza Rubab, Yiying Tong
**arXiv:** https://arxiv.org/abs/2609.38343

**相关性说明:** This paper is about 3D head avatar creation from single images using Gaussian splatting, which is a different application domain from the research profile. The research profile focuses on 3D MOTION GENERATION from video/2D priors (temporal motion), while this paper focuses on creating static 3D avatar geometry/appearance. The methods differ (Gaussian splatting + semantic inpainting vs video generation models + VLM for motion guidance), and the paper doesn't address any of the stated pain points: temporal consistency between video and motion, domain gap bridging for motion, quality supervision, or visual feature extraction for downstream motion models. While both are in Computer Graphics, they address fundamentally different problems.

**摘要:** SInGA是一种从单张图像学习语义修复以生成可动画化高斯头部头像的新方法，通过在UV空间中完成未观察区域并堆叠多个高斯来增强细节，能够在不进行身份特定优化的情况下跨身份泛化，支持逼真的动画和从未观察视图的一致渲染。
