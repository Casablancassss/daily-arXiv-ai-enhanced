## 📄 论文 1 - 相关性: 45%
**标题:** Progressively Learning Heterogeneous Skills in a Unified Latent Space
**作者:** Yue-Yi Zhang, Ming Gong, Linpu He
**arXiv:** https://arxiv.org/abs/2608.23258

**相关性说明:** Both papers are in Computer Graphics and deal with 3D motion generation. However, the research profile focuses on extracting 3D motion from 2D video using video generation models (万相, Seedance) and VLMs, while this paper (HetSkills) addresses physical character control through learning heterogeneous skills in a latent space. The application domains differ: the profile is about video-to-3D motion generation, while this paper is about skill-based character motion control. The methods are also different - the profile uses video generation models and VLMs, while this paper uses motion intuition distillation and task guidance modules. The pain points (extracting visual features from video, leveraging video generation models) are not addressed by this paper.

**摘要:** HetSkills是一个用于物理角色控制的新型框架，通过在统一潜在空间中逐步学习异构技能。该框架将潜在空间视为可执行接口，整合来自不同数据源、监督形式和任务的学习技能。


## 📄 论文 2 - 相关性: 45%
**标题:** Spatiotemporally Decoupled Autoregressive Diffusion Model for Human Motion Generation
**作者:** Chengqun Yang, Liang Xu, Yanping Li
**arXiv:** https://arxiv.org/abs/2608.23279

**相关性说明:** This paper addresses human motion generation but uses TEXT-driven synthesis, while the research profile focuses on extracting 3D motions from 2D VIDEO using video generation models (万相, Seedance) and VLM-based quality supervision. The application domain differs: text-to-motion vs video-to-3D-motion. The paper does address some quality concerns in 3D motion generation (one pain point), but doesn't address video feature extraction, leveraging video generation model priors, or bridging 2D visual features to 3D motion space - which are the core challenges in the research profile. It's moderately relevant as it's in the same general area of human motion generation, but misses the key video-related aspects.

**摘要:** 本文提出了DeMoDiff，一个统一的空间-时间解耦框架，用于文本驱动的人体动作合成。该框架重新设计了动作表示和生成架构，解决了基于VQ的方法存在的信息损失问题以及连续表示缺乏部分级灵活性的问题。


## 📄 论文 3 - 相关性: 35%
**标题:** WorldMind: Decoupled Game World Model for State-Aware NPC Behavior
**作者:** Zhiyang Deng, Boran Zhang, Danze Chen
**arXiv:** https://arxiv.org/abs/2608.21439

**相关性说明:** While this paper deals with video generation and game NPCs, it addresses a fundamentally different application domain. The research profile focuses on extracting 3D visual guidance features from 2D video and generating 3D human motion, while this paper focuses on game world models for NPC behavior generation in gaming contexts. The methods and goals are different - this paper is about game state understanding and NPC behavior planning, not 3D motion generation or bridging 2D visual features to 3D motion space. It uses a decoupled architecture for game AI rather than video-to-3D-motion generation pipelines.

**摘要:** WorldMind是一个解耦的游戏世界模型框架，通过四层架构（理解层、决策层、控制层、生成层）实现状态感知的NPC行为生成，解决了现有模型中NPC行为与视频生成紧密耦合的问题，并引入BOSS-140K数据集进行验证。


## 📄 论文 4 - 相关性: 35%
**标题:** Emotion Intensity Matters: Generating Realistic Expressions in Virtual Humans with CVAEs
**作者:** Vitor Miguel Xavier Peres, Lara Volpato, Gabriel Ferri Scnheider
**arXiv:** https://arxiv.org/abs/2608.21697

**相关性说明:** This paper addresses facial expression generation for virtual humans using CVAEs, which is in the broader Computer Graphics field. However, it has significant mismatches: (1) Application domain mismatch - the research profile focuses on 3D motion generation from 2D video with specific methods like video generation models and VLMs, while this paper focuses on facial expression synthesis using CVAE; (2) Method mismatch - the paper uses CVAE rather than the mentioned video generation models (万相, Seedance) and VLM-based quality supervision; (3) It doesn't address the pain points about extracting 3D visual guidance from 2D video or bridging 2D-3D gaps. While both relate to virtual humans, the technical approach and specific application (facial expressions vs. full 3D motion generation from video) are different.

**摘要:** 本文提出了一种基于条件变分自编码器(CVAE)的方法，用于从人类面部表情数据中合成可控制的不同强度的情感表情。该方法使用包含六种基本情绪(两种强度级别)的数据集进行训练,即使在有限数据量(仅7,680个样本)的情况下,也能学习有意义的潜在表示并生成连贯的情感变化。


## 📄 论文 5 - 相关性: 35%
**标题:** TransHands: Repurposing Human Pose Encoders as Hand Pose Encoders
**作者:** Milo Piccioli, Gianluca Amprimo, Claudia Ferraris
**arXiv:** https://arxiv.org/abs/2608.22341

**相关性说明:** The paper addresses 3D hand pose estimation using transfer learning from human pose data, which is different from the research profile's focus on video-to-3D motion generation. While both deal with human motion/pose, the application domain differs: the profile focuses on video generation models (万相, Seedance) for generating 3D motions from video, while this paper focuses on hand pose estimation from images/poses. The methodology (transfer learning from human to hand pose) is also not aligned with the video generation and VLM-based quality control methods specified in the profile. It's a moderately related field (human pose estimation) but doesn't directly address the pain points of extracting 2D visual features for 3D motion generation or leveraging video generation model priors.

**摘要:** TransHands是一个 backbone无关的迁移学习框架，将大规模人体姿态数据中学到的运动表征迁移到3D手部姿态估计任务中，通过两阶段训练和轻量级手部适配模块解决手部数据集稀缺的难题。
