# 📊 每日 arXiv 论文推荐

**研究画像:**
- 领域: Computer Graphics / Computer Vision
- 方法: Video generation models (万相, Seedance), Vision Language Models (VLM), 3D Motion Generation Models, Visual guidance feature extraction, Quality supervision and filtering pipeline
- 痛点: Difficulty in ensuring quality and reliability of generated 3D motions, Challenge of effectively bridging 2D video priors with 3D motion representation, Limited supervision signals for filtering high-quality visual guidance features, Gap between 2D visual features and semantically accurate 3D motion output

**最相关的 5 篇论文:**


## 📄 论文 1 - 相关性: 85%
**标题:** MoVT: Video-Augmented Motion Tokenizer for Text-to-Motion Generation
**作者:** Beibei Jing, Tianle Guo, Youjia Zhang
**arXiv:** https://arxiv.org/abs/2609.14965

**相关性说明:** Direct domain match - both focus on text-to-3D human motion generation in Computer Graphics/Vision. The paper directly addresses all key pain points: bridging 2D video priors with 3D motion (core method), quality enhancement through video augmentation, and addressing the gap between 2D visual features and semantically accurate 3D motion. Uses aligned 3D/2D codebook approach which is closely related to visual guidance feature extraction and quality supervision pipeline mentioned in profile. Highly relevant for research on 2D-to-3D motion synthesis.

**摘要:** MoVT是一个新型框架，通过利用大量人类动作视频来增强文本到动作的生成能力，解决3D动作训练数据有限的问题。


## 📄 论文 2 - 相关性: 50%
**标题:** MorphoStyle: Motion Style Transfer with Morphology Control
**作者:** Xin Feng, Eleonora D'Arnese, Mohan Sridharan
**arXiv:** https://arxiv.org/abs/2609.14189

**相关性说明:** The paper is in the same general field (Computer Graphics/Computer Vision for 3D motion generation), but addresses different pain points and uses different methods. The research profile focuses on bridging 2D video priors with 3D motion using VLM and diffusion models (Seedance, 万相), while this paper uses FSQ-VAE for motion style transfer with morphology control. Both are about 3D human motion but the specific application (video-to-motion generation with visual guidance) and methods (diffusion + VLM vs VAE-based style transfer) are different. The paper doesn't address 2D video priors or VLM-guided generation - it tackles a different problem: style-shape decoupling in motion generation.

**摘要:** MorphoStyle是一个基于形状条件的FSQ-VAE框架，用于实现形状感知的运动风格迁移。该方法解决了现有方法中运动风格与形状（形态）分离的问题，能够为非规范体型生成风格化运动。


## 📄 论文 3 - 相关性: 50%
**标题:** Reconstructing Is Not Acting: Action-Centric Latent Dynamics Modeling
**作者:** Dingjie Fu, Dianxing Shi, Yangyang Xu
**arXiv:** https://arxiv.org/abs/2609.15189

**相关性说明:** This paper addresses similar methodological challenges (latent action models, inverse/forward dynamics) but in ROBOTICS domain rather than human motion generation or character animation. While it touches on 3D motion representation, it's specifically for robot visual planning (VP² benchmark), not for computer graphics character animation or human motion synthesis. The methods (action queries, action tokens) differ from video generation models, VLMs, and visual guidance feature extraction mentioned in the profile. It's moderately relevant as a related but distinct application domain within computer vision/robotics.

**摘要:** 本文提出ACT-LAM框架，解决潜在动作模型(LAMs)中的重建-动作不匹配问题，通过动作查询逆动力学模型(AQ-IDM)和动作标记前向动力学模型(AT-FDM)增强动作提取和利用，在VP²基准上实现7.6%的成功率提升。


## 📄 论文 4 - 相关性: 35%
**标题:** Open-UniMo: Towards Unified Motion-Language Understanding and Generation in the Open World
**作者:** Guocun Wang, Kenkun Liu, Guorui Song
**arXiv:** https://arxiv.org/abs/2609.14615

**相关性说明:** This paper addresses text-to-motion generation using language models, but misses the core research profile requirements. The profile focuses on bridging 2D VIDEO priors with 3D motion generation (using models like 万相, Seedance), visual guidance feature extraction, and quality supervision pipelines. Open-UniMo uses TEXT as input, not video/2D visual priors. While it deals with 3D motion generation (relevant to Computer Graphics), it does not address the key pain points about visual-to-motion translation or quality filtering. The application domain is motion generation but the input modality is fundamentally different - text-based rather than vision-based.

**摘要:** Open-UniMo是一个统一的大规模运动-语言模型(LMLM),旨在解决现有模型中将运动作为语言模型辅助模态的问题。该模型通过扩展Qwen的词表,引入6.4万个运动标记,使运动和语言共享统一的标记空间,并引入运动一致的思维链推理作为中间表示来桥接语言语义和运动动力学。


## 📄 论文 5 - 相关性: 35%
**标题:** BVB: Benchmarking Agentic Video Understanding via Programmatic Reconstruction in Blender
**作者:** Yolo Y. Tang, Daiki Shimada, Jiayue Meng
**arXiv:** https://arxiv.org/abs/2609.15478

**相关性说明:** The paper focuses on VIDEO UNDERSTANDING via programmatic reconstruction in Blender, which is a different application domain from 3D MOTION GENERATION. While it uses Vision Language Models and mentions reconstruction, it addresses video analysis/understanding rather than generating 3D motions from video priors. The pain points in the profile are about quality/reliability of generated 3D motions, bridging 2D video with 3D motion representation, and visual guidance feature extraction for motion generation - none of which are addressed by this video understanding benchmark paper.

**摘要:** BVB是一个评估多模态智能体视频理解能力的基准测试，通过要求智能体用Blender编程重建视频来测试理解程度，优于传统问答评估。
